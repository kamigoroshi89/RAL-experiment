## Test

Written first and run to fail. Fixture values are hand-written test data; expected values are computed by hand as shown.

- `test_action_scoring_uses_validated_key`: a fixture key gives family F1 the options a (`expected`), b (`acceptable`), c (`incorrect`), d (`unsafe`); responses choosing a, b, c, d score correct = 1, 1, 0, 0 and unsafe = 0, 0, 0, 1.
- `test_per_condition_correct_share_hand_computed`: three participants with one scored vignette per condition give correct shares THR 1/3, ANOM 2/3, RSM 3/3 for the fixture responses (THR: P1 correct, P2 and P3 not; ANOM: P1 and P2 correct; RSM: all three).
- `test_unsafe_share_reported_separately`: one `unsafe` action in `THR` gives unsafe share 1/3 for `THR` and 0 for the others, without changing the correct shares.
- `test_practice_records_excluded`: records flagged `practice` change no statistic.
- `test_decision_time_median_and_hidden_time_exclusion`: `THR` times [12000, 18000, 30000] ms give median 18000; when the 30000 ms record has hidden time above the rule of `protocol.yaml` it is excluded from M2 only (median 15000) and stays in M1 and M3.
- `test_bootstrap_ci_degenerate_when_participants_identical`: when every participant has the same share 0.5, the interval is [0.5, 0.5].
- `test_bootstrap_resamples_participants_not_vignettes`: two participants, one always correct and one never correct (point estimate 0.5), give the interval [0.0, 1.0] for at least 200 replicates, because resampling participants yields 1.0, 0.5 or 0.0 with probabilities 1/4, 1/2 and 1/4.
- `test_bootstrap_seeded_reproducible`: the same integer seed from `protocol.yaml` gives identical intervals; the generator is `numpy.random.Generator` built from that seed.
- `test_holm_adjustment_hand_computed`: p-values [0.01, 0.04, 0.03] give adjusted [0.03, 0.06, 0.06] (sorted 0.01 x 3, 0.03 x 2, 0.04 x 1, made non-decreasing).
- `test_friedman_statistic_hand_computed`: three participants each scoring THR < ANOM < RSM give rank sums 3, 6, 9 and statistic 12 / (3 x 3 x 4) x (9 + 36 + 81) - 3 x 3 x 4 = 6.0.
- `test_trust_scoring_follows_protocol`: a fixture protocol with four items on a 7-point scale, item 2 reverse-coded, gives for ratings [7, 1, 6, 5] the item scores [7, 7, 6, 5] and mean 6.25 (fixture scale, not the real one; the real rule comes from `protocol.yaml`).
- `test_divergence_cell_table`: for four fixture block records (one per cell, two participants) the cell by action-class table and the cue-answer counts equal the hand counts.
- `test_divergence_contrast_paired`: participant P1 with concordant share 1.0 and divergent share 0.5, participant P2 with 1.0 and 0.0, give mean contrast (concordant minus divergent) 0.75.
- `test_rank_agreement_via_ralmon_eval`: identical rankings give 1.0 and reversed rankings give -1.0 through `severity_rank_agreement` imported from `ralmon.eval`; the participant rank is compared with the position produced by `rank_alerts` for the same set (order taken from the key file, never from the participant bundle).
- `test_template_has_no_hand_typed_numbers`: every digit sequence in `writeup.template.md` is inside a `{{...}}` placeholder or is an identifier (`RQ1` to `RQ5`, `M1` to `M5`, `C1` to `C3`, `B1`, `B2`, `R3-W6`, section signs and section numbers).
- `test_writeup_placeholders_all_resolved`: the generated `writeup.md` has no `{{` left and every placeholder key exists in `metrics.json`.
- `test_no_participant_level_rows_or_names`: the generated `writeup.md` contains no participant code (pattern of `protocol.yaml`), no per-participant table and none of the strings in a fixture list of forbidden names (a hospital name, a committee name and a person name as they would appear in the T05 artefact).
- `test_shortfall_labelled`: a fixture with 7 participants yields the phrase "descriptive pilot" in `writeup.md`; a fixture with 8 does not.
- `test_analysis_is_reproducible`: two runs on the same fixture and seed give byte-identical `metrics.json` and `writeup.md`.
