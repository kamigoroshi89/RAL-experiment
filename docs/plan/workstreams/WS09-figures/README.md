### Conventions shared by all generators

These are defined once in WS09-T01 (`tools/figures/style.py`, `fmt.py`, `provenance.py`) and reused by every target.

1. **No hand-typed numbers.** Every generated file begins with a `% GENERATED by tools/figures ...` header (`.tex`) or carries a `.data.json` sidecar (`.pdf`). The sidecar lists the plotted or tabulated values with their source keys, the path and SHA-256 of every input file, and the `git_rev.txt` of the source runs. `--check` regenerates in memory and fails if a generated file differs from disk or if an input hash changed. Numbers needed in paper prose (seeds, patient-days, alpha, tolerance, template count) are emitted as LaTeX macros in `paper/tables/*_macros.tex` for WS12 to `\input`.
2. **Missing is not zero.** A metric absent for a detector is rendered `n/a` (the contract rule: `None` never means "negative"). A run set with fewer than five seeds is refused (`02-interfaces.md#metrics`, analisi §5.1) unless `--allow-fewer-seeds` is given, in which case output is stamped `DRAFT` and `--check` fails.
3. **IEEE geometry.** Figures are created at their final printed size and included at scale 1: single column 3.5 in, double column 7.16 in (IEEEtran two-column values; WS12-T02 confirms them against the RA-L template `\columnwidth` and `\textwidth`). Fig. 1 is single column. No `bbox_inches="tight"` (it changes the size). Vector PDF, fonts embedded as Type 42 (no Type 3), text of at least 6 pt at final size, deterministic PDF metadata.
4. **Chart styling (dataviz).** One axis per chart (no dual axis); small multiples for many series; categorical hues assigned in fixed order per entity (methods B1-B5 and the proposed method keep the same colour, marker and line style in every figure); the palette is checked with the skill's validator; secondary encoding (marker, line style, hatch) so nothing depends on colour alone or survives only in colour print; a legend whenever there are two or more series, with direct labels on at most four; thin marks, recessive grid; text in text colours, never in series colours; verdict states use the status palette with glyphs and hatches. The sidecar `.data.json` plays the role of the skill's "table view".
5. **Terminology.** Labels follow `01-conventions.md` section 7: tier, module, node, forecaster, conformal calibrator, pathway template and patient care plan, DISPENSE and INTAKE, alert, violation, attributed cause; "robustness" only in the STL sense; "on-path" and "off-path" defined once (by WS12) and reused. Captions are written by WS12; generators supply tables, figures and macros, not captions. Any figure or table that reports coverage carries the qualifier "marginal over the population, not conditional on the patient" in its notes (`02-interfaces.md#conformal-calibrator`, rule 2).
6. **Determinism.** No wall clock, no unseeded randomness; regenerating from the same `outputs/` reproduces the `.tex` and `.data.json` files byte for byte (`01-conventions.md` section 3).

## Acceptance criteria

Run when WS09-T01 to WS09-T05 are done (and WS09-T06 if it is executed, that is if the lab demo was not cut). All commands from the repository root.

1. `pytest tests/figures -q` and `ruff check tools/figures tests/figures` exit 0.
2. `python -m tools.figures all` exits 0 and the files of the Outputs table (except Fig. 4 when OPTIONAL) exist (`test -f` on each).
3. `python -m tools.figures all --check` exits 0 (no generated file differs from a regeneration, no stale input hash, no DRAFT stamp).
4. `grep -L '^% GENERATED' paper/tables/*.tex` prints nothing, and every `paper/figures/*.pdf` has a `.data.json` beside it.
5. Table II has exactly the rows B1, B2, B3, B4, B5 and the proposed method and the columns F1 C1, F1 C2, F1 C3, false alarms per patient-day, median delay, coverage (test `test_table2_rows_and_columns`); Table III has a row for each of A1-A7 (test `test_table3_rows_and_ablation_labels`); Table I has one row per template of the library (test `test_table1_one_row_per_template_in_library`).
6. Fig. 1 satisfies the checklist of analisi §4.9 item 6 (tests `test_fig1_*`) and its PDF is one column wide: `grep -a -o '/MediaBox \[[^]]*\]' paper/figures/fig1_architecture.pdf` shows a width of 252 (3.5 in at 72 pt per inch).
7. Fig. 2 avoids the workshop Table I errors of analisi §4.6 (tests `test_model_*` in `tests/figures/test_fig2_patient_day.py`).
8. `grep -a -c '/Type3' paper/figures/*.pdf` prints 0 for every file (fonts embedded, no Type 3).
9. `grep -rniE 'subsystem|time-series learner|conformal uncertainty|edge cloud|\bPILL\b' paper/figures/*.data.json paper/tables/*.tex` prints nothing.
10. Removing one seed directory of `outputs/main/` makes `python -m tools.figures table2` exit non-zero with the missing path in the message.
11. `python3 tools/check_plan.py` reports no error for the files of this workstream (frontmatter complete, dependencies resolve, no placeholder token forbidden by rule 5 of the authoring brief).
