## Review mode and format

- Review mode: **double-anonymous.** Quote: "double-anonymous peer review process, where the identities of the reviewers are not known to the authors and the identities of the authors are not known to the reviewers"; "Do not use a cover page. Please leave space for an author byline, but do not include the author information in accordance with the double-anonymous review guidelines." Source: RA-L Information for Authors, Peer Review Model and Initial Submission, consulted 2026-10-08.
- Anonymisation rules (effective 1 January 2025): "Names and affiliations should not be included anywhere in the manuscript, appendix, and supplementary material."; "Acknowledgments to people or funding agencies should only be included after acceptance of the manuscript."; "Authors are allowed to use tools such as arXiv. Reviewers should not actively search for those articles to identify authors."; "Violations of those rules for material submitted for review can result in the paper being desk rejected." Paraphrase, not verbatim: no identifying links such as a GitHub repository (an anonymous mirror is suggested), and robot names hidden unless widespread. Source: https://www.ieee-ras.org/publications/rules-for-the-double-anonymous-review-process/, consulted 2026-10-08.
- Template: "For initial submission: use the ieeeconf.cls LaTeX class or ieeeconf_letter.dot Word template." Source: RA-L Information for Authors, consulted 2026-10-08.
- Supplementary material and video: multimedia may contain "videos (Only one video is allowed per submission), dataset files, source code, readme and instruction files"; "DO NOT submit supplemental text or figures as multimedia materials, as this would circumvent RA-L page limits"; a single ZIP of at most 50 MB. Source: RA-L Information for Authors, Multimedia Materials, consulted 2026-10-08.
- Code or data release: no mandatory rule; code and data are welcome as multimedia. Source: same page.
- Open tension: the evolutionary paradigm asks to disclose the prior version, double-anonymous review forbids identifying information; no page read resolves how to cite the workshop paper and its arXiv version anonymously.
